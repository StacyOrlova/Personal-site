# Stacy — Landing Page (Create React App, .js)

Портфолио-лендинг для Анастасии (Stacy), перенесённый на React (Create React App) с использованием файлов `.js` и без JSX-разметки (`React.createElement`).

## Запуск проекта

1. Установите зависимости:
   ```bash
   npm install
   ```

2. Запустите сервер разработки:
   ```bash
   npm start
   ```

3. Сборка для продакшена:
   ```bash
   npm run build
   ```
